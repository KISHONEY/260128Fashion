# 이후 확장 아이디어 (제안만 — 구현하지 않았습니다)

필요해지면 우선순위를 정해 하나씩 추가하는 것을 권합니다.

## 운영 편의
1. **비밀번호 재설정 메일** — 로그인 화면의 “비밀번호를 잊으셨나요?” (이메일 SMTP 설정 후 가능)
2. **오래된 업로드 파일 자동 정리** — 등록하지 않고 닫은 폼에 올린 파일을 주기적으로 지우는 예약 작업
3. **활동 기록** — 누가 언제 자료를 올리고 수정했는지 남기는 이력
4. **데이터 백업 내려받기** — 연구 자료 목록과 첨부 파일을 ZIP 으로 한 번에 내려받기

## 연구 아카이브
5. **연구 자료 공동 작성자** — 대학원생을 특정 연구의 공동 작성자로 지정해 수정 권한 부여
6. **학회·논문 정보 필드** — 학술지명, DOI, 발표 장소 등 출판 정보와 인용 형식(APA) 복사
7. **컬렉션(무드보드)** — 여러 연구 이미지를 묶어 주제별 보드로 보기
8. **이미지 캡션·출처 입력** — 이미지마다 설명과 저작권 표기
9. **한국어 검색 개선** — 형태소 분석 기반 전문 검색(PGroonga 등)으로 조사가 붙은 단어도 검색

## 수업
10. **과제 제출함** — 주차별로 학생이 파일을 제출하고 교수만 볼 수 있는 공간
11. **수업별 수강생 그룹** — 공개 대상을 “특정 과목 수강생”으로 좁히기
12. **공개 예약** — 지정한 날짜·시간에 자동으로 공개되는 수업 자료

## 토론 · 알림
13. **실시간 알림** — 새로고침 없이 종 아이콘 숫자가 바로 바뀌도록 (Supabase Realtime)
14. **주간 요약 메일** — 한 주 동안의 새 자료와 토론을 모아 월요일 아침에 발송
15. **이미지 위 코멘트** — 의상 사진의 특정 위치에 핀을 꽂아 피드백 (패턴·디테일 리뷰용)
16. **댓글 반응(공감)** — 짧은 동의 표시로 댓글 수를 줄이기

## 디자인 · 사용성
17. **다크 모드**
18. **홈 화면에 추가(PWA)** — 휴대폰 앱처럼 아이콘으로 실행, 오프라인에서도 최근 자료 보기
19. **영문 화면 전환** — 해외 공동연구자 초대 시
20. **선택적 공개 포트폴리오 페이지** — 교수가 고른 연구만 외부에 공개하는 별도 페이지 (현재는 전부 비공개)
