# 설정 가이드 (비개발자용)

이 문서만 따라 하면 **Supabase 가입 → 접속 정보 입력 → 배포(Vercel 또는 Netlify) → 교수 계정 만들기**까지 마칠 수 있습니다.
**환경변수는 넣지 않아도 됩니다.** 화면 그림 없이도 따라 할 수 있도록 눌러야 할 메뉴 이름을 **굵게** 적었습니다.

> 💡 서비스 화면은 가끔 바뀝니다. 메뉴 이름이 조금 다르면 비슷한 이름을 찾아 주세요.
> 브라우저 자동 번역을 켜 두면 메뉴 이름이 어색하게 바뀌니, 영어 원문으로 보는 것을 권합니다.

전체 소요 시간: 약 30~40분 · 비용: 무료 요금제로 시작 가능

---

## 준비물

- 이메일 주소 1개 (교수님 계정용)
- [GitHub](https://github.com) 계정 — 소스 코드는 저장소 `kisjeong/260128Fashion` 에 있습니다.
- 메모장 — 중간에 나오는 **주소, 키, 코드**를 잠시 적어 둘 곳

---

## 1단계. Supabase 가입하고 프로젝트 만들기 (약 10분)

Supabase 는 이 사이트의 **로그인, 데이터베이스, 파일 저장소**를 맡는 서비스입니다.

1. <https://supabase.com> 에 접속해 **Start your project** (또는 **Sign up**) 를 누릅니다.
2. **Continue with GitHub** 로 가입하는 것이 가장 간단합니다.
3. **New project** 를 누릅니다.
   - **Project name**: `fashion-archive` (아무 이름이나 괜찮습니다)
   - **Database Password**: **Generate a password** → 메모장에 복사
   - **Region**: `Northeast Asia (Seoul)`
   - **Create new project** → 1~2분 기다립니다.

## 2단계. 데이터베이스 만들기 — SQL 붙여 넣기 (약 3분)

1. 왼쪽 메뉴 **SQL Editor** → **New query** (또는 `+`)
2. 저장소의 [`supabase/schema.sql`](../supabase/schema.sql) 파일 내용을 **전체 복사**합니다.
   - GitHub 에서 파일을 열고 오른쪽 위 **복사 아이콘(Copy raw file)** 을 누르면 한 번에 복사됩니다.
3. 빈 칸에 붙여 넣고 오른쪽 아래 **Run** 을 누릅니다.
   - “destructive operation” 경고가 뜨면 **Run this query** 를 누르세요. (기존 규칙을 지우고 다시 만드는 명령이 있어서 뜨는 안내입니다)
4. 아래 **Results** 칸에 **최초 교수 가입 코드**(영문·숫자 10자리, 예: `3330BC5E02`)가 보입니다. → **메모장에 꼭 적어 두세요!** 6단계에서 씁니다.

> ✅ 이 SQL 은 여러 번 실행해도 안전합니다. 코드를 놓쳤다면 다시 Run 하면 같은 코드가 다시 보입니다.
> (교수 계정이 이미 만들어진 뒤에는 결과가 비어 있는 것이 정상입니다)

## 3단계. Supabase 로그인 설정 (약 1분)

학생이 **초대 코드로 직접 가입**할 수 있도록 설정합니다.
초대 코드가 없으면 데이터베이스가 가입을 거부하므로 아무나 가입할 수는 없습니다.

1. 왼쪽 메뉴 **Authentication** → **Sign In / Providers** (또는 **Providers**)
2. **Allow new users to sign up** → **켜기(ON)**
3. **Email** 항목을 눌러 **Confirm email** → **끄기(OFF)** → **Save**
   - 이걸 끄지 않으면 가입 후 인증 메일을 기다려야 하는데, Supabase 기본 메일은 학생에게 발송되지 않습니다.

## 4단계. 접속 정보 2가지를 코드에 넣기 (약 5분)

1. Supabase 왼쪽 아래 **Project Settings** (톱니바퀴)
   - **Data API** (또는 **API**) → **Project URL** 복사 → 메모장에 `URL:` 로 적기 (예: `https://abcdefghijk.supabase.co`)
   - **API Keys** → **Publishable key** (`sb_publishable_` 로 시작) 복사 → 메모장에 `공개키:` 로 적기
     (예전 화면이라면 “Legacy API keys” 의 `anon public` 키)
2. GitHub 저장소에서 [`src/config.ts`](../src/config.ts) 파일을 엽니다.
3. 오른쪽 위 **연필 아이콘(Edit this file)** 을 누릅니다.
4. 따옴표 안의 예시 글자를 지우고 내 값으로 바꿉니다. **따옴표는 그대로 둡니다.**

   ```ts
   export const SUPABASE_URL = "https://abcdefghijk.supabase.co";

   export const SUPABASE_PUBLISHABLE_KEY = "sb_publishable_xxxxxxxxxxxx";
   ```

5. 오른쪽 위 **Commit changes…** → 다시 **Commit changes** 를 누릅니다.

> 🔐 이 두 값은 원래 공개되도록 만들어진 값이라 코드에 넣어도 안전합니다. (데이터는 Supabase 권한 규칙이 보호합니다)
> ⚠️ 같은 화면의 **Secret key** (`sb_secret_…`) 는 **절대 코드에 넣지 마세요.** 이 사이트는 Secret key 없이 동작합니다.
> 💬 직접 수정하기 어려우면 URL 과 공개키를 개발 담당자(또는 Claude)에게 알려 주고 대신 넣어 달라고 하셔도 됩니다.

## 5단계. 배포하기 — Vercel 또는 Netlify 중 **한 곳만** (약 10분)

둘 다 무료이고 방법이 비슷합니다. **환경변수 입력 칸은 비워 두고 넘어가면 됩니다.**

### A. Vercel 을 쓰는 경우

1. <https://vercel.com/signup> → **Continue with GitHub**
2. **Add New…** → **Project** → 저장소 **260128Fashion** 옆 **Import**
   - 목록에 없으면 **Adjust GitHub App Permissions** 로 이 저장소 접근을 허용
3. **Framework Preset** 이 `Next.js` 인지 확인하고 **Deploy**
4. 2~3분 뒤 축하 화면이 나오면 **Continue to Dashboard** → **Domains** 에 보이는 주소가 사이트 주소입니다. (예: `https://260128-fashion.vercel.app`)

### B. Netlify 를 쓰는 경우

1. <https://app.netlify.com> → GitHub 로 로그인 → **Add new project** → **Import an existing project** → **GitHub** → **260128Fashion**
2. **Project name**: 영어 소문자·숫자·하이픈으로 겹치지 않는 이름 (예: `kisjeong-fashion-archive`) — 빨간 오류가 사라지면 사용 가능한 이름입니다.
3. **Branch to deploy** 는 그대로, 나머지 빌드 설정도 그대로 두고 **Deploy** 를 누릅니다.
4. 사이트 주소는 `https://정한이름.netlify.app` 입니다.

> 이미 환경변수를 넣어 두었다면(`NEXT_PUBLIC_SUPABASE_URL` 등) 지우지 않아도 됩니다. 환경변수가 있으면 그 값이 우선 사용됩니다.
> 단, 값이 틀리거나 `k` 처럼 잘못 들어간 변수는 지워 주세요.

### 배포 후 Supabase 에 사이트 주소 알려 주기

Supabase → **Authentication** → **URL Configuration**
- **Site URL**: 사이트 주소로 바꾸고 **Save**
- **Redirect URLs** → **Add URL** → `사이트주소/**` (예: `https://260128-fashion.vercel.app/**`) → **Save**

## 6단계. 교수님 계정 만들기 (약 2분)

1. 사이트 주소 뒤에 `/join` 을 붙여 엽니다. (예: `https://260128-fashion.vercel.app/join`)
2. **초대 코드**에 2단계에서 적어 둔 **최초 교수 가입 코드**를 넣습니다.
3. 이름, 이메일, 비밀번호(8자 이상)를 입력하고 **가입하고 시작하기**
4. 위쪽 메뉴에 **관리**가 보이면 성공입니다! 🎉

> 최초 교수 가입 코드는 **한 번만** 쓸 수 있습니다. 학생 초대는 [첫 사용 가이드](02-첫-사용-가이드.md) 를 보세요.

### 확인 체크리스트

- [ ] 로그아웃한 상태에서 `사이트주소/research` 를 직접 열어도 로그인 화면으로 이동한다
- [ ] 교수님 계정으로 로그인하면 **관리** 메뉴가 보인다

## (선택) 내 컴퓨터에서 실행해 보기

배포 전에 확인하고 싶을 때만 하세요.

1. <https://nodejs.org> 에서 **LTS** 버전 설치
2. GitHub 저장소의 초록색 **Code** → **Download ZIP** → 압축 풀기 (4단계에서 config.ts 를 수정한 뒤에 받으세요)
3. 터미널(Mac: “터미널”, Windows: “PowerShell”)에서 `cd ` 입력 후 압축 푼 폴더를 끌어다 놓고 Enter
4. 아래 명령을 차례로 입력

   ```bash
   npm install
   ```

   ```bash
   npm run dev
   ```

5. 브라우저에서 <http://localhost:3000> 열기 · 끝낼 때는 터미널에서 `Ctrl + C`

## (선택) 추가 기능 — Secret key 가 필요한 기능

기본 기능은 모두 Secret key 없이 동작합니다. 아래 기능이 꼭 필요할 때만 설정하세요.
Secret key 는 **코드가 아니라** Vercel/Netlify 의 **환경변수**에만 넣어야 합니다.

| 기능 | 필요한 환경변수 |
| --- | --- |
| 이메일로 초대 메일 보내기 | `SUPABASE_SECRET_KEY` + Supabase SMTP 설정 + 초대 메일 문구 변경 |
| 멤버 제거 시 로그인 계정까지 완전 삭제 | `SUPABASE_SECRET_KEY` |
| 멘션 시 이메일 알림 | `SUPABASE_SECRET_KEY`, `RESEND_API_KEY`, `EMAIL_FROM` |

- Vercel: 프로젝트 → **Settings** → **Environment Variables** (Production·Preview·Development 모두 체크) → 저장 후 **Deployments** 에서 **Redeploy**
- Netlify: 프로젝트 → **Project configuration** → **Environment variables** → **Add a variable** → 저장 후 **Deploys** → **Trigger deploy**

**이메일 발송 준비**: Supabase 기본 메일은 학생에게 보낼 수 없으므로 [Resend](https://resend.com) 같은 메일 서비스가 필요합니다.
1. Resend 가입 → **Domains** 에서 도메인 인증 → **API Keys** 에서 키 발급
2. Supabase → **Authentication** → **Emails** → **SMTP Settings** → Enable Custom SMTP
   - Host `smtp.resend.com`, Port `465`, Username `resend`, Password = Resend API 키, Sender = `noreply@인증한도메인`
3. Supabase → **Authentication** → **Emails** → **Templates** → **Invite user** 의 Body 를 아래로 바꾸고 **Save**

```html
<h2>연구 아카이브에 초대되었습니다</h2>
<p>아래 버튼을 눌러 이름과 비밀번호를 정하면 가입이 완료됩니다.</p>
<p>
  <a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=invite&next=/auth/set-password"
     style="display:inline-block;padding:12px 20px;background:#171614;color:#ffffff;text-decoration:none">
    초대 수락하기
  </a>
</p>
<p style="color:#6d6860;font-size:12px">이 링크는 한 번만 사용할 수 있으며 일정 시간이 지나면 만료됩니다.</p>
```

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 사이트에 “설정이 필요합니다” 가 보임 | 4단계의 `src/config.ts` 값을 확인 (따옴표 안, 앞뒤 빈칸 없이). 수정 후 자동으로 다시 배포됩니다 |
| 빌드 로그에 `환경변수 … 가 설정되지 않았습니다` | 예전 버전의 코드입니다. GitHub 의 최신 코드로 다시 배포하세요 |
| 가입 시 “Supabase 에서 회원가입이 꺼져 있습니다” | 3단계 2번 (Allow new users to sign up 켜기) |
| 가입했는데 “인증 메일을 확인해 주세요” 가 나옴 | 3단계 3번 (Confirm email 끄기). 이미 가입한 계정은 Supabase → **Authentication** → **Users** 에서 해당 줄 `⋯` → **Confirm email** |
| 가입 시 “유효하지 않거나 만료된 초대 코드” | 코드 철자 확인. 최초 교수 코드는 2단계 SQL 을 다시 Run 하면 다시 보입니다 |
| 교수 계정인데 **관리** 메뉴가 안 보임 | 아래 “교수 권한 직접 주기” SQL 실행 |
| 사진 업로드 시 “업로드 권한이 없습니다” | 2단계 SQL 이 끝까지 실행됐는지 확인 (**Storage** 에 `archive` 버킷이 있어야 함) |

**교수 권한 직접 주기** — SQL Editor 에서 실행:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = '교수님이메일@example.com');
```
