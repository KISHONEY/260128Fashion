# 첫 사용 가이드

[설정 가이드](01-설정-가이드.md)를 마쳤다면 이제 사이트를 사용할 수 있습니다.
아래 순서대로 한 번씩 해 보세요. (약 15분)

---

## 1. 교수 계정으로 로그인하기

1. 사이트 주소(예: `https://260128-fashion.vercel.app`)에 접속합니다.
2. 설정 가이드 6단계에서 **최초 교수 가입 코드**로 만든 이메일과 비밀번호로 로그인합니다.
3. 위쪽 메뉴에 **관리**가 보이면 교수(관리자) 계정입니다.

> 다른 교수님(공동 연구자)을 관리자로 추가하려면 초대 코드를 만들 때 권한을 **교수(관리자)**로 고르세요.

## 2. 홈 화면의 교수 소개 채우기

1. **관리** → **교수 소개** 탭
2. **사진 올리기**를 눌러 프로필 사진을 고릅니다. (자동으로 적당한 크기로 줄어듭니다)
3. 이름, 직함·소속, 연구 분야(쉼표로 구분), 소개, 연락처를 입력하고 **저장**
4. **홈**으로 가면 바로 반영되어 있습니다.

## 3. 학생 초대하기

### 방법 A. 초대 코드 (추천 — 별도 설정 없이 바로 사용)

1. **관리** → **멤버 · 초대** 탭
2. **초대 코드** 영역에서
   - 권한: `대학원생`
   - 사용 가능 인원: 초대할 학생 수 (예: 5명이면 `5`)
   - 유효 기간: 기본 7일 (0 이면 기한 없음)
   - 메모: `2026 신입 석사` 처럼 알아보기 쉬운 이름
3. **초대 코드 만들기** → 오른쪽 목록에 8자리 코드가 생깁니다.
4. **초대 안내문 복사**를 누르면 가입 주소와 코드가 함께 복사됩니다. 카카오톡이나 문자로 학생에게 보내세요.

학생은 안내문의 주소를 열고 **이름 · 이메일 · 비밀번호**를 입력하면 바로 가입됩니다.

> 🔒 코드는 정한 인원만큼만 쓸 수 있고 기간이 지나면 자동으로 막힙니다. 더 이상 필요 없으면 **삭제**하세요.
> 이미 가입한 학생에게는 영향이 없습니다.

### 방법 B. 이메일 초대 (선택)

설정 가이드의 “(선택) 추가 기능”을 설정한 경우에만 관리 화면에 나타납니다.
**이메일로 초대**에 학생 이메일을 넣고 **초대 메일 보내기** → 학생이 메일의 **초대 수락하기**를 눌러 이름과 비밀번호를 정합니다.

### 멤버 관리

- **권한** 칸에서 대학원생 ↔ 교수(관리자)를 바꿀 수 있습니다. (본인 권한은 바꿀 수 없습니다)
- 졸업 등으로 접근을 막을 때는 **제거**를 누르세요. 즉시 모든 자료에 접근할 수 없게 되고, 그 학생이 쓴 댓글은 “탈퇴한 멤버”로 남습니다.
- 제거한 학생을 같은 이메일로 다시 받으려면, 먼저 Supabase → **Authentication → Users** 에서 그 이메일 줄의 `⋯` → **Delete user** 로 로그인 계정을 지운 뒤 새 초대 코드를 보내 주세요.

## 4. 첫 연구 자료 올리기

1. **연구** → 오른쪽 위 **+ 연구 자료 등록**
2. **제목**과 **요약**(카드에 보이는 짧은 소개)을 입력합니다.
3. **이미지 · 첨부 파일** 상자에 사진, PDF, PPT 등을 **끌어다 놓습니다**. (휴대폰에서는 **파일 선택**)
   - 이미지는 자동으로 크기가 조정되고 썸네일이 만들어집니다.
   - **첫 번째 이미지가 대표 이미지**입니다. ↑↓ 버튼으로 순서를 바꿀 수 있습니다.
   - 올릴 수 있는 형식: 이미지(JPG·PNG·WEBP·GIF), PDF, PPT/PPTX, DOC/DOCX, XLS/XLSX, HWP/HWPX, TXT · 파일당 최대 50MB
4. **상세 설명**에 연구 내용을 씁니다. **미리보기** 탭에서 어떻게 보일지 확인할 수 있습니다.
5. 오른쪽에서 **카테고리 · 연도 · 상태(진행중/완료/발표/출판) · 태그**를 고릅니다.
   - 태그는 입력 후 Enter. 처음 쓰는 태그는 자동으로 만들어집니다.
6. 업로드가 모두 끝나면(“파일 업로드 중…” 표시가 사라지면) **연구 자료 등록**을 누릅니다.

등록 후 상세 화면에서 이미지를 누르면 크게 볼 수 있고(← → 키나 손가락으로 넘기기), 아래쪽 **토론**에서 학생들과 의견을 나눌 수 있습니다.
수정·삭제는 상세 화면 오른쪽의 **수정 / 삭제** 버튼으로 합니다.

### 마크다운 간단 사용법

| 이렇게 쓰면 | 이렇게 보입니다 |
| --- | --- |
| `## 연구 배경` | 큰 소제목 |
| `**강조**` | **강조** (굵게) |
| `- 항목` | • 목록 |
| `[학회 페이지](https://...)` | 링크 |
| `> 인용문` | 인용 상자 |

> 💡 굵게 표시 바로 뒤에 조사가 붙고 앞이 기호(%, ) 등)로 끝나면 굵게 적용이 안 될 수 있습니다.
> 예: `**15%**에` → `**15%** 에` 처럼 한 칸 띄우거나 `**15%에**` 로 쓰세요.

## 5. 수업 자료 올리기

1. **수업** → **+ 수업 자료 등록**
2. **학기**(예: `2026-2`), **과목명**, **주차**를 입력합니다. 한 번 입력한 학기·과목은 다음부터 목록에서 고를 수 있습니다.
   - 주차를 `0` 으로 두면 강의계획서 같은 **공통 자료**로 표시됩니다.
3. PDF·PPT·이미지를 올리거나, **외부 링크 추가**에 유튜브·구글 드라이브 주소를 넣습니다.
4. **공개 대상**: `전체 멤버 공개` 또는 `비공개 (교수만)` — 비공개 자료는 학생에게 목록·주소·파일 모두 보이지 않습니다. 준비 중인 자료를 미리 올려 둘 때 쓰세요.

## 6. 토론 · 알림 사용하기

- 모든 자료 아래 **토론**에 의견을 남길 수 있습니다. 이미지 첨부, 마크다운, **답글**(1단계)을 지원합니다.
- `@` 를 입력하면 멤버 목록이 나타납니다. 이름을 고르면 그 사람에게 **알림**이 갑니다.
- 교수님은 중요한 댓글을 **고정**(맨 위에 표시)하거나 어떤 댓글이든 **삭제**할 수 있습니다.
- 위쪽 🔔 종 아이콘의 숫자는 읽지 않은 알림입니다. 알림을 누르면 해당 댓글로 이동합니다.
  - 교수님은 연구·수업 자료에 새 의견이 달리면 알림을 받습니다.
  - 내 댓글에 답글이 달리거나 누군가 나를 @멘션하면 알림을 받습니다.
- **연구실 라운지**는 자료와 상관없는 자유 게시판입니다. 학생도 글을 쓸 수 있고, 교수님은 공지처럼 **상단 고정**할 수 있습니다.

## 7. 학생에게 전달할 안내 (복사해서 쓰세요)

> 연구실 아카이브 사이트를 열었습니다. 아래 주소에서 초대 코드로 가입해 주세요.
> 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.
> - 연구 자료와 수업 자료를 보고, 각 자료 아래 **토론**에 의견을 남겨 주세요.
> - 질문할 사람이 있으면 `@이름` 으로 불러 주세요.
> - 자료는 연구실 내부용입니다. 외부 공유는 삼가 주세요.
> - 이메일 알림을 원하지 않으면 오른쪽 위 내 정보 → **내 정보 설정**에서 끌 수 있습니다.

## 자주 묻는 질문

**Q. 학생이 비밀번호를 잊었어요.**
교수님이 Supabase → **Authentication → Users** 에서 그 학생을 찾아 줄을 누른 뒤 비밀번호를 새로 정해 알려 주세요.
(학생은 로그인 후 **내 정보 설정**에서 다시 바꿀 수 있습니다)

**Q. 사진을 올렸는데 화질이 떨어져요.**
보기 편하도록 긴 변을 2000픽셀로 줄여 저장합니다. 화면 감상에는 충분한 크기입니다. 인쇄용 고해상도 원본은 PDF 로 만들어 첨부하거나 별도로 보관하세요.

**Q. 저장 공간은 얼마나 쓸 수 있나요?**
Supabase 무료 요금제는 파일 1GB, 데이터베이스 500MB입니다. 이미지가 자동으로 줄어들기 때문에 수백 건의 연구 자료를 올릴 수 있습니다.
Supabase 대시보드 → **Project Settings → Usage**(또는 **Billing**)에서 사용량을 확인하세요.

**Q. 무료 프로젝트가 멈췄다고 메일이 왔어요.**
Supabase 무료 프로젝트는 일주일간 아무도 접속하지 않으면 일시 정지됩니다. Supabase 대시보드에서 **Restore project** 를 누르면 다시 켜집니다. (데이터는 그대로입니다)
